Gizlilik Politikası

Son güncelleme: 6 Kasım 2026

OddPebble Automation, OddPebble kanalının sahibi tarafından kullanılan kişisel bir YouTube video yükleme ve planlama aracıdır. Bu web sitesi uygulamayı tanıtır; Google girişi, video yükleme formu veya hesap kaydı sunmaz.

Erişim ve işlenen bilgiler

Araç, hesap sahibinin OAuth izniyle YouTube Data API hizmetlerini kullanır. Video yüklemek için youtube.upload; bağlı kanalı ve yüklenen videonun durumunu doğrulamak için youtube.readonly izni ister. Kanal adı ve kimliği, video kimliği, gizlilik ve işlenme durumu ile yükleme ve doğrulama kayıtları işlenebilir.

Saklama ve hizmet sağlayıcıları

Uzun süreli yetkilendirme bilgileri şifreli GitHub Actions secret olarak saklanır. Videolar, yayın bilgileri ve işlem kayıtları sahibinin özel GitHub deposunda tutulur. Yetkilendirme için kullanılan geçici bulut ortamı bağlantı tamamlandıktan sonra silinir. Google şifresi uygulama tarafından istenmez veya saklanmaz.

İşlemlerin yürütülmesi için Google/YouTube ve GitHub hizmetleri kullanılır. Veriler yalnızca sahibinin seçtiği yükleme, planlama ve doğrulama işlemlerinde kullanılır. Reklam, veri satışı veya yapay zekâ modeli eğitimi için kullanılmaz. Mevcut uygulama yapay zekâ sağlayıcılarına veri göndermez.

Google API verilerinin sınırlı kullanımı

OddPebble Automation’ın Google API’lerinden aldığı bilgileri kullanması ve başka bir uygulamaya aktarması, Limited Use koşulları dahil Google API Services User Data Policy hükümlerine uyar.

Erişimi kaldırma ve silme

Sahibi, Google hesap bağlantıları üzerinden erişimi iptal edebilir ve GitHub’daki yetkilendirme secret’ını silebilir. Bu işlemler, daha önce yüklenmiş YouTube videolarını veya depodaki kayıtları otomatik olarak silmez. Videolar YouTube Studio’dan; dosyalar, kayıtlar ve gerektiğinde depo geçmişi GitHub üzerinden ayrıca yönetilir. Uygulamada otomatik veri silme süresi tanımlanmamıştır.

Bu web sitesinin ziyaret edilmesi

Bu statik sitede reklam veya uygulamaya özel analiz aracı bulunmaz. GitHub Pages, hizmetin sunulması ve güvenliği için IP adresi gibi teknik istek bilgilerini işleyebilir. İlgili sağlayıcıların saklama ve gizlilik uygulamaları kendi politikalarına tabidir: Google Gizlilik Politikası ve GitHub Gizlilik Bildirimi.

İletişim

Uygulama yöneticisi: zeyyoutube-ux. Uygulama hakkındaki sorular için GitHub iletişim alanı kullanılabilir. Bu alan herkese açıktır; burada token, parola veya özel kişisel bilgi paylaşılmamalıdır.
